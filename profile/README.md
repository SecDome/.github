# SecDome

> **Securing Systems with AI. Securing AI with Systems.**

SecDome is a security research laboratory and engineering matrix operating at the intersection of machine intelligence and software systems. We investigate the safety boundaries of frontier models and autonomous agents, while harnessing artificial intelligence to advance automated vulnerability discovery, system defense, and empirical verification.

---

### Core Research Pillars

- **Foundation Model & Agent Security**: Adversarial robustness, guardrail alignment, and provable state-shielding for autonomous agents.
- **Automated Code Intelligence**: Compiler-grade program analysis, semantic taint tracking, and multi-agent 0-day verification pipelines.
- **Empirical Benchmarks & Verification**: Standardized, 100% reproducible evaluation suites across exploit generation, patch validation, and model resilience.
